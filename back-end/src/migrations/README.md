# Устаревшие миграции (Deprecated)

> [!WARNING]
> **ВНИМАНИЕ: ДАННАЯ ДИРЕКТОРИЯ И ФАЙЛ `back-end/src/schema.sql` УСТАРЕЛИ!**  
> **Единый источник истины схемы БД:** `supabase/migrations/` в корне монорепозитория.

## Контекст и статус

1. **Несогласованность:** Исторические файлы миграций в данной папке (`001`, `004`, `005`, `006`, дублирующийся `007`, `008`, `009`, `011`) имеют пропуски нумерации и не отражают актуальное состояние живой базы данных. Файл `schema.sql` также не синхронизирован с рабочей базой.
2. **Сохранение файлов:** Данные файлы **НЕ удаляются и НЕ переносятся**, так как на них ссылаются существующие автоматические тесты проверки безопасности (`back-end/security-tests/`).
3. **Новый процесс:**
   - Базовый слепок схемы (baseline) снимается с живой базы данных (`pg_dump`) и фиксируется в виде отдельной миграции в `supabase/migrations/`.
   - Полная инвентаризация используемых таблиц, колонок и RPC функций зафиксирована в [docs/db-schema-inventory.md](../../../docs/db-schema-inventory.md).
   - Любые последующие изменения базы данных вносятся **исключительно** через новые файлы миграций в `supabase/migrations/` с помощью Supabase CLI (`supabase db push`).
